# Gravity arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.
#
# The item sprite says what this arrow does with a second shape, a smaller cube
# already falling away beneath the head. That shape cannot come along: it sits
# off the axis, and the renderer mirrors this profile onto itself, so a cube
# slung under the shaft would return as two cubes rather than as one falling.
# The read has to come from the head alone, so the head is the only blunt one in
# the mod. It is a full five by five slime cube with a flat front, where every
# other arrow here tapers to a point, and that squared-off silhouette is what
# says weight while it is still moving.
#
# Slime's darker inner cube is kept as a three by three core inside the paler
# shell, which is what separates it from any other green block, and the front
# face carries the light so the cube still reads as lit rather than as a flat
# green square once it has cross-hatched with its own mirror.
#
# canvas = 32
#

# c = 8AD164  slime, lit front face

# d = 336E26  slime, inner cube

# S = 896727  shaft, body
# w = 5E4619  shaft, nock shadow
# F = E0E0E0  fletching, light
# f = C6C6C6  fletching, mid
