# Wind arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.
#
# The item sprite's open ring is the one silhouette in the mod with a hole in it,
# and it is worth keeping here even though the hole is a single pixel, because a
# gap survives the mirrored profile in a way that a shading choice does not: the
# copies overlay hole on hole rather than lit edge on shadow. The ring is closed
# on all four sides around that pixel so it never breaks into a pair of unrelated
# specks from a shallow angle. Pale and cold throughout, since the glow ink sac is
# the other light head and the two must not merge while both are in the air.
#
# canvas = 32
#
# c = E2F6F8  ring, lit facet
# m = A9CFD2  ring, body
# d = 6E969B  ring, inner shadow
# O = 3E5E63  ring, collar, where the head meets the shaft
# W = A8802F  shaft, grain highlight
# S = 896727  shaft, body
# w = 5E4619  shaft, nock shadow
# F = E0E0E0  fletching, light
# f = C6C6C6  fletching, mid
