# Redstone arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.
#
# The crystal stays the shortest and squarest head in the mod, held inside rows 1
# to 3 so it never bulges the way the glow ink sac does. That is the whole
# separation between the two at speed, because both are utility arrows carrying a
# coloured lump on the tip and colour alone does not survive the mirrored profile.
# The hot core sits one pixel back from the point rather than on it, so the facet
# behind the tip is the brightest thing on the arrow and the signal reads as
# carried inside the crystal instead of smeared along the whole head.
#
# canvas = 32
#
# c = FF3B3B  crystal, lit facet
# h = FFD6D6  crystal, hot core
# m = D71414  crystal, body
# d = 8A0F0F  crystal, inner shadow
# O = 3B0505  crystal, collar, where the head meets the shaft
# W = A8802F  shaft, grain highlight
# S = 896727  shaft, body
# w = 5E4619  shaft, nock shadow
# F = E0E0E0  fletching, light
# f = C6C6C6  fletching, mid
