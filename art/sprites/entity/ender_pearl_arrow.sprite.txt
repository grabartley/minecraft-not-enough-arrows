# Ender pearl arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.
#
# The item sprite's dark core is the one thing worth carrying over, and it is also
# the one thing that survives being drawn four times around the axis: it sits on
# the centre line, so the mirrored copies land core on core rather than lit edge on
# shadow. Everything else about the head is mass and tone along its length: it stands
# the full five rows of the profile band the moment it leaves the collar, holds that
# for three columns, then tapers to a single lit pixel at the point. Held darker than
# the glow ink sac, which is the other teal head in the air.
#
