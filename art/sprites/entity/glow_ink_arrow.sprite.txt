# Glow ink arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.
#
# The sac keeps the item sprite's round swell but moves it onto the axis, because
# the profile is drawn mirrored on top of itself and a sac slung under the shaft
# would read as two sacs. It bulges a full pixel past the shaft on both rows 0 and
# 4, which is the widest head of the three utility arrows and the thing that tells
# it from the redstone arrow's angular crystal while both are moving. The spout
# keeps a single glow speckle at the tip so the head still reads as lit rather
# than as merely teal once the sac colour has cross-hatched with its own mirror.
#
# canvas = 32
#
# h = C8FFEF  sac, glow speckle
# c = 5FDCC8  sac, lit facet
# m = 27A79B  sac, body
# d = 12706B  sac, inner shadow
# O = 0B3B3C  sac, collar, where the head meets the shaft
# W = A8802F  shaft, grain highlight
# S = 896727  shaft, body
# w = 5E4619  shaft, nock shadow
# F = E0E0E0  fletching, light
# f = C6C6C6  fletching, mid
