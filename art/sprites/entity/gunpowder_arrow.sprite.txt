# Gunpowder explosive arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.
#
# The entry tier carries the shortest head in the family and the only unbarbed
# one, held inside row 2 so its silhouette is a plain spike. That is deliberate:
# the four explosive arrows are separated in flight by how far the head reaches
# and whether it carries barbs, because the mirrored profile flattens colour
# first and a player picking a tier mid-fight is reading length, not hue.
#
# canvas = 32
#

# m = 7E7E88  blade, body
# d = 5A5A64  blade, inner shadow
# W = A8802F  shaft, grain highlight
# S = 896727  shaft, body
# w = 5E4619  shaft, nock shadow
# F = E0E0E0  fletching, light
# f = C6C6C6  fletching, mid
