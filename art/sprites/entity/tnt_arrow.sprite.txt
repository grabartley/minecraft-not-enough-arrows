# TNT explosive arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.#
# The head is built with mass rather than as a line: it swells to the full five
# rows of the profile band at its shoulder and tapers to a single lit pixel at
# the point, with the outer rows held in the darkest tone and the centre line the
# brightest. That shading is symmetric about the shaft on purpose, because the
# renderer mirrors this profile onto itself and any top-to-bottom gradient would
# come back as a two tone lump. Symmetric tone is what survives, and it is what
# gives the head volume instead of leaving it reading flat at speed.
#
# Tier two carries more mass than tier one and a barb pair on the outer rows. The
# white band inlaid down the flat runs through the centre of the head, which is
# the mark that separates it from the fire charge arrow once both are red and
# moving.
#
# canvas = 32
#
# H = FF7A55  blade, lit edge
# c = E8492E  blade, bright facet
# B = DDD9D9  band inlaid down the flat
# m = DB2F1A  blade, body
# d = 912D11  blade, inner shadow
# O = 4A0F08  barb and shadowed outer facet
# W = A8802F  shaft, grain highlight
# S = 896727  shaft, body
# w = 5E4619  shaft, nock shadow
# F = E0E0E0  fletching, light
# f = C6C6C6  fletching, mid
