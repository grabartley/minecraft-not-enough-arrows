# Rope arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.
#
# The head stays narrow, an anchor point rather than the grapple's claw, and the
# hemp coil riding the shaft carries the identity: it is the one silhouette break
# a player can still pick out once the arrow is moving. Both are shaded symmetric
# top to bottom because the model draws this profile mirrored on top of itself, so
# any gradient across them would show as a two tone lump from most angles. The
# shaft carries a grain ramp instead of the item sprite's lit and shadowed faces,
# because at one pixel tall there is no second face to shade.
#
# canvas = 32
#
# H = B4C1CE  anchor, lit tip
# m = 6E7A88  anchor, body
# d = 3E454F  anchor, collar, where the head meets the shaft
# t = D8C69B  rope, strand
# r = A89168  rope, mid
# R = 6B5A3A  rope, groove
# W = A8802F  shaft, grain highlight
# S = 896727  shaft, body
# w = 5E4619  shaft, nock shadow
# F = E0E0E0  fletching, light
# f = C6C6C6  fletching, mid
