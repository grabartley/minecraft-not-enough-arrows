# Grapple arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.
#
# The head is the same cold blue steel as the item sprite's grapnel claw, splayed
# into three tines so it reads as something that bites rather than pierces. Its
# shading is symmetric top to bottom because the model draws this profile mirrored
# on top of itself, so any gradient across the tines would show as a two tone head
# from most angles. The shaft carries a grain ramp instead of the item sprite's lit
# and shadowed faces, because at one pixel tall there is no second face to shade.
#
# canvas = 32
#
# H = B4C1CE  claw, lit edge
# m = 6E7A88  claw, body
# d = 3E454F  claw, inner shadow, where the head meets the shaft
# W = A8802F  shaft, grain highlight
# S = 896727  shaft, body
# w = 5E4619  shaft, nock shadow
# F = E0E0E0  fletching, light
# f = C6C6C6  fletching, mid
