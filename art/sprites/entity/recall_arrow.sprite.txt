# Recall arrow in flight.
#
# Rows 0-4 are the side profile, nock at x0 to tip at x15. Rows 5-9 columns 0-4
# are the fletching cross seen end on. The Textures section of the README covers
# why only that corner of the canvas is ever sampled.
#
# The same profile the ender pearl arrow flies, with the tone turned inside out.
# A lit core on the centre line rather than a dark one, which is the reading that
# survives being drawn four times around the axis, since the mirrored copies land
# core on core. In the air the pair separates the way it does in the hand: the
# pearl is a bright head with a dark middle and this is a dark head with a bright
# one, so a player watching an arrow arc knows which way the ender trip is going.
#
# canvas = 32
#
# c = 8A63C6  shell, lit point
# m = 4E2E78  shell, body
# h = EFE0FF  core, the throw held in reserve
# d = 30194D  shell, inner shadow
# O = 1A0E2B  shell, collar, where the head meets the shaft
# W = A8802F  shaft, grain highlight
# S = 896727  shaft, body
# w = 5E4619  shaft, nock shadow
# F = E0E0E0  fletching, light
# f = C6C6C6  fletching, mid
