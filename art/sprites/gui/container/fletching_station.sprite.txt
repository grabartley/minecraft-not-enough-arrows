# The fletching station screen background.
#
# 176 by 166 laid out on the 256 by 256 canvas a container background is drawn from,
# so the screen can use the plain drawTexture path the way vanilla's own containers do.
#
# The slot coordinates are not a choice made here. FletchingStationLayout already fixes
# the three by three input grid at 30,17, the result at 124,35 and the player inventory
# at 8,84, which happen to be the vanilla crafting table's own coordinates, so the wells
# are drawn under those and nothing in this file may move without moving that class too.
#
# What is a choice is the strip between the input grid and the result. The station picks
# a recipe the way a stonecutter does, so that strip carries a recipe list and its
# scrollbar rather than the crafting table's arrow. Forty pixels is what the layout
# leaves there, which buys one column of recipes and a scrollbar rather than the
# stonecutter's four columns: the list well floor is 16 wide by 54 tall at 87,16, so
# three 16 by 18 recipe buttons are visible at a time and the rest are scrolled to.
#
# Sprite regions, all in texture space:
#
#   panel                 0,0    176 x 166
#   input slot wells      29,16   18 x 18 each, pitch 18, three by three
#   result slot well      123,34  18 x 18
#   recipe list floor     87,16   16 x 54, three 16 by 18 rows visible
#   scroll track floor    107,16  12 x 54, the 12 x 15 scroller travels 39 of it
#   player inventory      7,83    18 x 18 each, pitch 18, nine by three
#   hotbar                7,141   18 x 18 each, pitch 18, nine
#   title anchor          8,6
#   inventory label       8,72
#   list row, idle        0,166   16 x 18
#   list row, hovered     16,166  16 x 18
#   list row, selected    32,166  16 x 18
#   scroller              48,166  12 x 15
#   scroller, disabled    60,166  12 x 15
#
# The input and result slots are the standard vanilla recess and deliberately carry no
# art of their own. A player reads a slot by its bevel, and a station that decorated its
# slots would be saying they behave unusually when they do not.
#
# The row states are under the panel on this same sheet rather than in the GUI atlas, so
# the screen reads every region it needs out of one texture. They separate on where the
# lit face sits before they separate on hue: idle is raised with the light up and left,
# hovered closes that into a bright ring on all four sides, and selected inverts the bevel
# outright into a dark recess lit from below and right. Desaturate all three and they are
# still three different controls, which colour alone would not survive.
